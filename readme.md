# Proyecto Módulo Seminarios Odoo - ISI | Judibeth Coronado.

## 1. Instrucciones para Levantar el Entorno
1. Clona el repo: `git clone https://github.com/judibethh/odoo-seminarios-proyecto.git`
2. `cd odoo-seminarios-proyecto`
3. `docker-compose up -d`
4. Accede a http://localhost:8069, crea DB.

## 2. Pasos para Instalar y Probar
1. En Odoo, actualiza apps.
2. Instala "Seminar Attendance ISI".
3. Usa menú "Seminarios" para crear/inscribir/marcar.

## 3. Uso de Herramientas de IA
- Herramientas: Grok.
- Prompts: "Genera modelo seminar.py para Odoo", "Crea vistas XML para seminario".
- Ayuda: resolvió sintaxis, ahorró tiempo.
